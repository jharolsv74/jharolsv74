## Trabajo de titulación

### [Visita Sigchos](https://github.com/jharolsv74/visita-sigchos)

Plataforma web turística para el cantón Sigchos, provincia de Cotopaxi. Catálogo de atractivos con persistencia en Supabase y cálculo de rutas entre puntos de interés mediante la API de OpenRouteService.

`Next.js` `TypeScript` `Tailwind CSS` `Supabase` `OpenRouteService`

## Arquitectura de Software y Sistemas Distribuidos

### [Microservicios Hospitalarios](https://github.com/jharolsv74/microservicios_u3)

Arquitectura de microservicios dockerizados para gestión hospitalaria. Cuatro servicios independientes —pacientes, médicos, turnos y notificaciones— comunicados de forma asíncrona mediante RabbitMQ con un modelo de publicación y suscripción de eventos.

El diseño desacoplado permite escalar cada componente por separado y manejar la concurrencia en la asignación de turnos sin mantener estado compartido entre servicios.

`Spring Boot` `RabbitMQ` `React` `TypeScript` `Docker Compose` `PostgreSQL`

### [Orquestación de Servicios](https://github.com/jharolsv74/orquestacion_pry)

Orquestación de un flujo de reserva de viajes integrando múltiples servicios backend a través de MuleSoft, como proyecto de la asignatura de Arquitectura de Software.

`MuleSoft` `Spring Boot` `Integración de APIs`

## Pruebas técnicas

### [Task Manager](https://github.com/jharolsv74/taskManager)

Sistema de gestión de tareas con autenticación stateless por JWT, roles y permisos, CRUD completo con estados configurables, testing con `@SpringBootTest` y despliegue containerizado con Docker Compose.

`Java 21` `Spring Boot 3` `Spring Security` `JWT` `JPA / Hibernate` `React 18` `Vite` `Docker`
